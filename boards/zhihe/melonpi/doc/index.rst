Zhihe Melon Pi
==============

The ``melonpi/a210/e902`` target runs on the E902 always-on processor.
Uses the A210 module SY70209 and SY70300 power wiring.

See :zephyr:code-sample:`scmi_server` for the boot contract, resources,
protocol exposure and validation limits. The application processor is
not supported by this target. Hardware execution remains unverified.
